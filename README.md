# Python Mini Banking System

A menu-driven Banking System developed using Python functions as part of a Python programming mini-project. This project demonstrates fundamental Python programming concepts through practical banking operations.

## Project Overview

The Python Mini Banking System simulates basic banking operations through an interactive command-line interface. Users can create accounts, check balances, deposit money, withdraw funds, transfer money between accounts, and view transaction history.

The application uses Python functions to modularize banking operations and dictionaries for in-memory data storage.

## Features

- **Account Creation** – Create a new bank account with account number, name, and initial balance.
- **Balance Enquiry** – Check the current account balance.
- **Deposit Money** – Deposit funds into an existing account.
- **Withdraw Money** – Withdraw funds with insufficient balance validation.
- **Fund Transfer** – Transfer money between two existing accounts.
- **Transaction History** – View account transaction records.
- **Interactive Menu** – Navigate banking operations through a menu-driven interface.
- **Exit System** – Exit the application gracefully.

## Technologies Used

- Python 3
- Python Functions
- Dictionaries

- Conditional Statements

- User Input Handling

## Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab

### Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/python-mini-banking-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-mini-banking-system
   ```

3. Open the notebook:

   ```bash
   jupyter notebook
   ```

4. Open `Mini_Project_using_Function_in_Python_Banking_Domain.ipynb` and execute the cells.

## Data Storage

The application uses in-memory Python dictionaries to maintain:

- Account details
- Account balances
- Transaction history

**Note:** Data is stored only during program execution. Account information and transaction history are not persisted after the application terminates.
